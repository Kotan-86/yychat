# バグ修正仕様の例

## ファイル名

```
app/docs/spec/bugs/42_map-marker-duplication.md
```

## 再現手順 — 良い例

条件を具体化し、期待値と実際の差異を書く。

```markdown
### 再現手順

1. ログイン済みで `/home` を開く
2. 画面上部チップを「わいわいリクエスト」ON にする
3. 地図上の同一スポットを 3 回連続でタップする

**期待値**: マーカーは 1 つだけ表示される
**実際**: 同一位置にマーカーが 2 つ重なって表示される
```

## 再現手順 — 悪い例

```markdown
### 再現手順

1. 地図を触る
2. たまにマーカーが重なる
```

→ 「たまに」は曖昧。操作・状態・期待値と実際の差異を具体化する。

## 修正方針 — 良い例

How（ソースコード）ではなく、あるべき挙動で書く。

```markdown
### 修正方針

同一スポット ID のマーカーは、地図上に常に 1 つだけ表示する。チップ切り替えや再タップ後も重複表示しない。
```

## 修正方針 — 悪い例

```markdown
### 修正方針

`markers.filter` で重複を除去し、`useEffect` の依存配列を修正する。
```

→ 実装詳細（How）。ユーザー視点・データのあるべき姿で書き直す。

## 受入基準 — 良い例

```markdown
## 受入基準（再発防止・回帰テスト）

1. **再現手順の検証**: 上記再現手順 1〜3 を実行しても、同一スポット位置にマーカーが 2 つ以上表示されない。
2. **影響範囲・回帰テスト**: わいわいスポットモード・わいわいリクエストモードの切り替え後も、マーカーの表示・非表示が従来どおり動作する。
```

## 追記・変更理由 — 更新時

```markdown
## 変更・追記理由（更新時のみ）

- issue #42: 調査の結果、再現は連続タップ時のみではなく、チップ切り替え直後にも発生することが判明したため、再現手順と受入基準を更新した。
```
