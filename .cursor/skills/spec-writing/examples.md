# 仕様書の例

`app/docs/spec/bottom-nav-unauthenticated.md` より抜粋。

## 見出しと Issue

```markdown
# 未ログイン時の下部ナビ — スタンプボタン非表示

## Issue

#7
```

## 目的（Why）— 良い例

背景とユーザーへの影響を書く。実装方法は書かない。

```markdown
## 目的（Why）

スタンプラリーはログイン済みユーザーのみ利用できる機能である。未ログイン時に下部ナビゲーションへ「スタンプ」ボタンが表示されたままだと、タップしても利用できず混乱を招く。未ログイン時はスタンプへの導線を出さず、利用可能な「ニュース」「検索」およびわいわいリクエストモード時の「リクエスト」に絞ることで、操作可能な UI だけを見せる。
```

## 実現内容（What）— 良い例

条件と振る舞いを表や箇条書きで具体化する。

```markdown
## 実現内容（What）

### 1. 対象ユーザー

- **未ログイン**（OIDC サインイン前で、アカウントに紐づく `userId` がない状態）のみ本仕様を適用する。
- **ログイン済み**ユーザーは、現行仕様のまま変更しない。

### 2. 未ログイン時の下部ナビ（4個目ボタン）

| 画面上部チップ（地図モード）         | 4個目ボタン（未ログイン時）                                |
| ------------------------------------ | ---------------------------------------------------------- |
| わいわいスポット ON（`YYSpot`）      | **表示しない**（スタンプボタンを出さない）                 |
| わいわいリクエスト ON（`YYRequest`） | **表示する**（ラベル・アイコンは現行どおり「リクエスト」） |
```

## 受入基準 — 良い例

番号付きで、前提条件と期待結果をセットにする。

```markdown
## 受入基準

1. **未ログイン・わいわいスポット ON**: サインインせず `/home` を開き、画面上部チップが「わいわいスポット」ON のとき、下部ナビに「スタンプ」ラベルのボタンが存在しない。
2. **未ログイン・わいわいリクエスト ON**: サインインせず画面上部チップを「わいわいリクエスト」ON にしたとき、下部ナビ 4個目に「リクエスト」ラベルのボタンが表示されている。
```

## 変更理由 — 更新時

```markdown
## 変更理由

- issue #7: 未ログイン時は下部メニューのスタンプラリーボタンを非表示にし、ニュースと検索（およびわいわいリクエストモード時のリクエスト）が見える状態にする。
```

## 避ける例

| 悪い例                        | 理由                                                               |
| ----------------------------- | ------------------------------------------------------------------ |
| 「適切にエラーを表示する」    | 曖昧でテスト不能                                                   |
| 「`useState` で状態管理する」 | How（実装詳細）                                                    |
| 「バグを直す」                | What が不明確                                                      |
| Issue 番号なし                | 追跡できない（ただし、ユーザが明示的に「なし」と言った場合は例外） |
