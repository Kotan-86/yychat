# Pull Request 説明文の例

## 記入済みの例

```markdown
## 変更内容

未ログイン時、わいわいスポットモードでは下部ナビのスタンプボタンを非表示にした。

## 変更の理由

未ログインでスタンプボタンをタップしても利用できず混乱を招くため、操作可能な導線（ニュース・検索・リクエスト）に絞る。

## 関連Issue

Closes #7

## 関連する仕様

- app/docs/spec/bottom-nav-unauthenticated.md

## チェックリスト

- [x] テストが通る
- [x] 仕様を更新した（必要な場合）
- [x] 動作確認した
```

## gh pr create コマンド例

```bash
git push -u origin HEAD

gh pr create --title "feat: 未ログイン時にスタンプボタンを非表示にする" --body "$(cat <<'EOF'
## 変更内容

未ログイン時、わいわいスポットモードでは下部ナビのスタンプボタンを非表示にした。

## 変更の理由

未ログインでスタンプボタンをタップしても利用できず混乱を招くため、操作可能な導線（ニュース・検索・リクエスト）に絞る。

## 関連Issue

Closes #7

## 関連する仕様

- app/docs/spec/bottom-nav-unauthenticated.md

## チェックリスト

- [x] テストが通る
- [x] 仕様を更新した（必要な場合）
- [x] 動作確認した
EOF
)"
```

## 説明文のみ生成するとき

push や PR 作成は依頼がない限り行わない。テンプレートに沿った本文だけを出力する。

## 避ける例

| 悪い例                         | 理由                             |
| ------------------------------ | -------------------------------- |
| 変更内容が実装詳細の羅列       | What（何を変えたか）が伝わらない |
| 変更の理由が空                 | Why がレビュアーに伝わらない     |
| 仕様リンクなし（仕様変更あり） | 仕様とコードの整合が確認しづらい |
